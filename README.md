# Live Content Updater

This is a simple JavaScript project that allows users to update part of a webpage's content in using an input field and a button. When the user enters text and clicks the update button, the specified content on the page changes instantly without reloading the page.

![Live Content Updater](./images/preview.png)

---
## Features
- Updates UI text instantly on button click
- Prevents empty, null, and whitespace-only values from being displayed

---
## Tech Stack
- HTML5
- CSS3
- JavaScript
